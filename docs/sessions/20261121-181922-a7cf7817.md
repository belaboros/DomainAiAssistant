**What's built** (in [workflows/](apps/ontology-builder/src/ontology_builder/workflows/)):
- **Open:** opening an ontology takes a one-process lock in the work folder. A lock left by a process that is no longer running is taken over. Opening also undoes any write that was interrupted half-way.
- **Unsaved changes survive a restart:** every review action is written to a journal file in the work folder. On reopen the journal is applied again. If the dataset changed on disk in the meantime, opening is refused unless you pass `discard_journal`.
- **Save:**
  - It is refused if git is missing, HEAD is detached, a merge is in conflict, or the dataset changed on disk since it was opened ("reload").
  - Otherwise it writes the changed records and decisions, rebuilds the raw release, swaps the staging copy in and commits only the dataset folder.
  - If a hook fails, the dataset is swapped back, you get the hook's output, and the unsaved changes are kept for the next try.
- **Publish:** domain admin only, and only with nothing unsaved. It makes one commit and records a `publish` decision.
- **Ingest and resume:** the estimate is shown before any LLM call. A successful run writes everything plus the raw release in one commit. A run that fails half-way leaves `git status` clean and can be resumed.
- **Create:** creates and commits a new ontology. If the commit fails, the new folder is removed again.
